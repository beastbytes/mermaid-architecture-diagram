Installation
============

The preferred way to install this extension is through `composer <https://getcomposer.org/download/>`__.

Either run

``php composer.phar require --prefer-dist beastbytes/mermaid-architecture-diagram``

or add

``"beastbytes/mermaid-architecture-diagram": "{{versionConstraint}}"``

to the ``require`` section of your composer.json.
